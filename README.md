#  BlackWipe

> **Anti-forensic tool for authorized security testing and privacy protection.**
> For Red Team operations and privacy defense.

---

## 📖 Description

BlackWipe is an anti-forensic tool designed for security professionals. It securely erases logs, modifies file timestamps, cleans registry keys, and overwrites free space to prevent forensic recovery.

---

## ⚠️ Warning

**This tool is for authorized use only.** Always obtain written permission before use.

---

## ⚙️ Installation

```bash
git clone https://github.com/theanonspider/BlackWipe.git
cd BlackWipe
pip install -r requirements.txt

🚀 Usage

# Create token
